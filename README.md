# LinkOut VPN

Сервис подписок на VPN с Telegram-ботами для пользователей и администраторов. Здесь представлены возможности проекта и его архитектура.

## Что делает сервис

- Проводит пользователя через выбор тарифа, оплату, активацию и продление подписки.
- Поддерживает административное подтверждение платежей и автоматическую обработку уведомлений платёжного провайдера.
- Синхронизирует доступ и лимиты устройств с внешней VPN-панелью.
- Обрабатывает напоминания об окончании подписки, реферальные бонусы и обращения на выплаты.
- Собирает агрегированную аналитику заказов, подписок и пользовательского пути.

## Технологии и архитектура

**Python · FastAPI · aiogram · SQLAlchemy · PostgreSQL · Alembic · Docker Compose · pytest**

```mermaid
flowchart LR
    U[Бот пользователя] --> S[Бизнес-логика]
    A[Бот администратора] --> S
    P[Платёжные уведомления] --> API[FastAPI] --> S
    S --> DB[(PostgreSQL)]
    S --> V[VPN-панель]
    S --> PAY[Платёжный API]
```

Ключевые решения: разделение пользовательского и административного интерфейсов, подтверждение оплаты до выдачи доступа, защита от повторной обработки платёжных уведомлений, миграции базы данных и автоматические тесты. В проекте проходит 482 теста.
